# Orange 人工截图计划

当前只有计划，没有截图或生成的图片。是否拍摄、最终选图与公开授权由用户决定；不自动 capture。README Hero 使用明确文字 placeholder，不链接尚不存在的文件。

## 共同安全与版式规则

仅从 fresh Public Synthetic Demo 开始，用公开虚构选项，不输入真实资料。所有目标都排除真实姓名、学号、邮箱、电话、精确地址、私有 evidence / profile / Memory、凭据、浏览器账号、终端、开发者绝对路径。隐藏浏览器 chrome、侧栏账号／本机地址和桌面；不使用私有 Golden Case。

保留橙色品牌、当前任务、authority 标签与必要免责声明，不能通过裁剪把 draft 伪装成 confirmed，或把兴趣伪装成能力。截图不是新证据，也不证明 live AI 或就业效果。优先 1440–1600px 宽 viewport，正文裁剪约 16:10；长页用分段自然裁剪，不拼接成不存在的 UI，不拉伸。

## Assets 与人工接入

[docs/assets/README.md](assets/README.md)定义资产准入。拍摄后先人工检查隐私、标签、语义与许可证，再按上述稳定文件名加入 `docs/assets/`；只有文件实际存在后才添加 README image link。Hero 建议只选一张；其余按叙事需要取舍，不做截图墙。建议 PNG（文字清晰）或质量合适的 WebP；无外部 logo、字体包、模板截图或 stock artwork。

人工选图待定是 USER DECISION REQUIRED，不是技术／隐私 blocker。若候选图片包含私有资料，则该图片 BLOCKED，不可发布。
