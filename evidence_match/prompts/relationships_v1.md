# evidence_relationship@v1

只比较一个已确认用户与一个 source-grounded 合成代表性角色。
输出 request-scoped 用户/工作 signal IDs 和有界关系候选，不输出证据 ID、解释自由文案、行动、分数、百分比、排名或职业决定。
DIRECTLY_SUPPORTED 只支持具体活动；RELATED_BUT_PARTIAL 必须保留有限范围；UNKNOWN 是材料不足，不是弱点；TENSION 需要明确双侧依据；NOT_APPLICABLE 需要明确范围依据。
兴趣不证明能力；capabilities_involved 不是 required qualification。候选经独立确定性验证，不得修复、替换 ID 或补造事实。无隐藏推理输出。
